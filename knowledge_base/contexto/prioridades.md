# Prioridades Globales del Proyecto

Este documento enumera las prioridades globales del proyecto en orden de importancia para guiar decisiones de entrenamiento, nutrición, recuperación y programación.

1. Estética muscular
2. Postura
   - Hipercifosis
   - Hiperlordosis
   - Hombros rotados
   - Caja toracica colapsada
   - Cuello
   - Triceps
   - Cadera
3. Hipertrofia
   - Hombros
   - Bíceps
   - Espalda
   - Tríceps
   - Pecho
   - Abdominales
4. Flexibilidad
   - Triceps
   - Ingle
5. Estrés (especialmente niveles de cortisol)
6. Salud hormonal
7. Vitalidad
8. Salud digestiva
9. Agilidad
10. Cardio

## Uso
1. Usar este orden como criterio global para priorizar objetivos del proyecto.
2. La programación y la selección de métricas deben alinearse con estas prioridades.
