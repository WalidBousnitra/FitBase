# Preferencias de Ejercicios del Usuario

> **Propósito**: Ejercicios que el usuario prefiere, evita o tiene limitaciones.
> La IA usa esta info para GENERAR el plan, no es el plan en sí.

---

## 1. Ejercicios Favoritos

> Estos ejercicios deben priorizarse en la selección.

| Grupo | Ejercicios Preferidos |
|-------|----------------------|
| Pecho | Press inclinado, Cruces polea alta |
| Espalda | Remo neutro, Dominadas, Remo unilateral con rotación, Kelso shrug |
| Hombros | Elev. laterales sentado, Elev. laterales polea media |
| Bíceps | Curl Z, Zottman, Curl predicador |
| Tríceps | Press francés 30°, Extensiones unilaterales polea |
| Pierna | Sentadilla, Hip thrust, RDL |
| Core | Plancha, Hollow hold/rock, Press Pallof |

---

## 2. Ejercicios Excluidos

> NUNCA incluir estos en el plan.

| Ejercicio | Razón |
|-----------|-------|
| Press banca plano | Preferencia (no le gusta) |
| Curl martillo | Preferencia |
| Peso muerto sumo | Preferencia |
| Agarres cerrados (espalda) | Preferencia |
| Prensas en máquina | Inefectivos (percepción) |

---

## 3. Limitaciones Físicas

| Zona | Problema | Ejercicios a Evitar |
|------|----------|---------------------|
| Codo | Dolor nervioso/tendinoso | Extensión completa bajo carga en tríceps |

---

## 4. Preferencias de Equipamiento

| Preferencia | Valor |
|-------------|-------|
| Peso libre vs Máquinas | **Peso libre preferido** |
| Mancuernas vs Barra | Ambos OK |
| Poleas | OK |

## 5. Preferencias de Sesión

| Variable | Valor |
|----------|-------|
| Duración mínima | 60 min |
| Duración ideal | 75 min |
| Duración máxima | 90 min |
| Cardio junto a pesas | No (separado) |
