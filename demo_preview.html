Notas técnicas de esta versión

Timer: Usa Handler + SystemClock.elapsedRealtime() (no CountDownTimer, no MediaSession).
Notificación con DecoratedCustomViewStyle + RemoteViews custom.
Al terminar: fullScreenIntent → heads-up garantizado incluso con pantalla off.
Canal CANAL_TIMER_RELOJ con IMPORTANCE_HIGH + vibración [0,200,100,200]ms.

Plan Anual: formatearFecha() limpia CUALQUIER formato (T, GMT, milisegundos).
Si str_rir_rango contiene una fecha por error → muestra "—".
Fase actual: fondo #1A3D5C + borde naranja 2dp + badge pill "ACTUAL".

Progresión: ProgressionActivity solicita permisos HC con registerForActivityResult.
Si HC devuelve 0 registros → mensaje diagnóstico con pasos exactos para Zepp sync.

Colores: Fondo #0F1419 (azulado), accent #FF6D3B, macros coloreados,
progress bars con gradiente, botones con gradient naranja.
