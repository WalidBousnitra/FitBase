Despliegue FitBase

7 pasos para tener la app corriendo. Marca cada checkbox y avanza en orden.

0 de 7 pasos completados
1
Crear Google Sheet
~5 min

Creamos la hoja de cálculo que será la base de datos.

  1. Ir a sheets.new en el navegador
  2. Renombrar a FitBase_BD
💡 No necesitas copiar el ID: El script se crea desde esta misma Sheet, así que ya está vinculado automáticamente.
2
Inicializar las 14 Hojas
~3 min

El backend creará automáticamente las 15 hojas con sus headers al ejecutar inicializarHojas().

⚡ Tip: No crees las hojas manualmente. El script lo hace con los headers correctos.

Las 15 hojas que se generarán:

usuarios, metricas_zepp, peso_log, sesiones_plan, ejercicios_plan, ejercicios_log, progresion_log, comidas_log, hidratacion_log, suplementos_log, excepciones_log, plan_anual, plan_semanal, ejercicios_catalogo, mediciones_log
2b
Configurar FatSecret API
~5 min

FitBase importa calorías y macros directamente desde FatSecret.

  1. Crear cuenta en platform.fatsecret.com
  2. Crear aplicación → obtener Client ID y Client Secret
  3. Generar Access Token (OAuth 2.0 Client Credentials)
  4. En Apps Script: Archivo → Propiedades del proyecto
  5. Añadir propiedad: FATSECRET_ACCESS_TOKEN = tu token
FATSECRET_ACCESS_TOKEN = eyJ0eXAi...tu_token_aqui
🔗 Sync: Al abrir FitBase cada día, importa automáticamente lo registrado en FatSecret. Registra ahí tus comidas y FitBase lo recoge.
3
Crear Apps Script
~5 min
  1. Desde la Sheet: Extensiones → Apps Script
  2. Borrar todo el contenido del editor
  3. Pegar el contenido completo de Codigo.gs
  4. Guardar (Ctrl+S)
🔗 Vinculado automáticamente: Al crear el script desde la Sheet, ya está asociado. No necesitas configurar ningún ID manualmente.
4
Ejecutar inicializarHojas()
~2 min
  1. En el editor Apps Script, seleccionar función: inicializarHojas
  2. Clic en ▶️ Ejecutar
  3. Aceptar permisos (tu cuenta de Google)
  4. Verificar en la Sheet que aparecen las 15 pestañas
🔐 Permisos: Google te pedirá autorizar. Como eres el owner, clic en "Avanzado → Ir a FitBase (no seguro)" para aprobar.
5
Desplegar como Web App
~3 min
  1. En Apps Script: Implementar → Nueva implementación
  2. Tipo: Aplicación web
  3. Ejecutar como: Yo
  4. Acceso: Cualquier persona
  5. Clic Implementar
  6. Copiar la URL de implementación
https://script.google.com/macros/s/TU_DEPLOY_ID/exec
📋 Guardar: Esta URL es tu API_BASE_URL. La necesitarás en el siguiente paso.
6
Configurar Android
~10 min
  1. Abrir el proyecto Android en Android Studio
  2. En util/Constants.java, pegar tu URL:
public static final String API_BASE_URL = "https://script.google.com/macros/s/TU_DEPLOY_ID/exec";
  1. Sync Gradle (barra superior → Sync Now)
  2. Verificar: Min SDK 26, Target SDK 34, Java 17
compileSdk = 34 minSdk = 26 targetSdk = 34 sourceCompatibility = JavaVersion.VERSION_17
7
Build & Run
~5 min
  1. Conectar dispositivo físico (USB debugging) o emulador API 26+
  2. Clic ▶️ Run 'app'
  3. Verificar pantalla de inicio con macros del día
  4. Probar una sesión de entrenamiento demo
✅ Validación: Si ves los macros (3280 kcal, 156g P, 488g C, 78g G) y la sesión planificada, ¡todo funciona!
